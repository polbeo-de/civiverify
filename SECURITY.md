# Security Policy

## Supported versions

Security fixes are provided for the latest published CiviVerify release.

## Reporting a vulnerability

Report suspected vulnerabilities privately to
<mcc+civiverify@polbeo.de>. Do not disclose the issue publicly until
maintainers have had a reasonable opportunity to investigate and coordinate a
fix.

Include a description, affected version, reproduction steps, and potential
impact. Maintainers will acknowledge the report and communicate the next
steps.
