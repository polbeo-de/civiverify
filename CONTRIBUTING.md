# Contributing

Thank you for contributing to CiviVerify. Please read the README and the
architecture decisions in `docs/adr/` before proposing a change.

## Before submitting

- Discuss substantial changes with the maintainers first.
- Keep changes focused and include tests or documentation where relevant.
- Run `composer lint` and `composer test` before submitting a pull request.
- Do not include credentials, real contact data, generated logs, or local
  environment configuration.

## Pull requests

Describe the problem, solution, validation performed, and any compatibility or
security impact. By contributing, you agree that your contribution may be
distributed under this repository's license.
